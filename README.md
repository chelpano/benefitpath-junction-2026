# BenefitPath

**BenefitPath** is an AI-powered assistant developed for the **Junction 2026 hackathon**, as part of the **Exa Challenge**.

## About the project

BenefitPath helps foreign residents in Finland who face language barriers understand the Finnish social benefit system.

Users can describe their situation in English. The application uses Exa to search current information from official Finnish sources, retrieves relevant content, and uses AI to explain possible support options in simple English.

## Key features

- Search for relevant information from official Finnish sources.
- Explain complex benefit rules in simple English.
- Compare published requirements with the user's situation.
- Show original sources and links.
- Provide personalized next steps and a practical checklist.

## Target audience

Foreign residents in Finland who have difficulty navigating the social benefit system because of language barriers or unfamiliarity with Finnish public services.

## Technology

- **Exa API** — web search and content retrieval.
- **JavaScript** — application logic.
- **HTML & CSS** — user interface.
- **Node.js** — backend.
- **AI** — analysis and explanations.

## Important note

BenefitPath provides preliminary informational guidance. It does not determine official eligibility or replace decisions made by Kela or other public authorities.
